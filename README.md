# Clothing Repair Cost Calculator (Python)

Sistema desenvolvido em Python para calcular o valor total do conserto de roupas com base na quantidade de peças informadas.

## Funcionalidades

- Calcula o valor total automaticamente
- Aplica acréscimo de 10% para 3 ou mais peças
- Interface simples via terminal
- Código limpo e fácil de entender

## Regra de negócio

- Cada peça custa R$ 5,00
- Para 3 ou mais peças, é aplicado acréscimo de 10%

## Tecnologias utilizadas

- Python 3
